# Averti Website UI Direction Guide

## Project Overview

This project is for **Averti Professional Managers**, a professional consulting and advisory firm.

The website should feel like a premium executive consulting brand with a modern editorial aesthetic.

The visual direction is inspired by:

* McKinsey.com
* Successory.org

The goal is NOT to create:

* a startup SaaS website
* a flashy agency portfolio
* a trendy tech landing page

The website should communicate:

* trust
* expertise
* sophistication
* professionalism
* strategic thinking
* executive credibility

---

# Core Visual Direction

The design language should feel:

* Minimal
* Editorial
* Spacious
* Structured
* Sophisticated
* Calm
* Premium
* Executive
* Modern but timeless

The experience should rely heavily on:

* typography hierarchy
* spacing
* composition
* image presentation
* layout rhythm
* subtle motion

NOT on:

* heavy visuals
* decorative UI
* excessive effects
* loud components

---

# Layout Philosophy

## Prioritize White Space

The layouts should breathe.

Avoid:

* cramped sections
* dense grids
* excessive cards
* oversized content blocks

Use:

* generous padding
* large vertical spacing
* clean alignment
* structured content flow

---

# Editorial Composition

The layouts should feel editorial rather than template-based.

Use:

* asymmetrical layouts
* alternating content/image sections
* layered composition
* balanced negative space

Avoid:

* repetitive generic sections
* identical stacked cards everywhere
* overly boxed layouts

---

# Typography Direction

Typography is one of the most important aspects of the design.

The text should feel:

* elegant
* highly readable
* premium
* structured

Use:

* strong heading hierarchy
* restrained font sizing
* spacious line heights
* balanced paragraph widths

Avoid:

* oversized hero text everywhere
* compressed text blocks
* excessive font weights
* playful typography

---

# Image Direction

ONLY use images from the existing `/public` folder.

DO NOT:

* generate placeholder images
* use random stock photography
* use remote images

Images should feel:

* refined
* intentional
* integrated into the layout

Use:

* elegant cropping
* subtle overlays
* rounded corners where appropriate
* layered image layouts
* image-text balance

Avoid:

* giant banner images
* cluttered galleries
* overly decorative image treatments

---

# Motion & Animation Direction

Use Framer Motion for subtle premium interactions.

Animations should feel:

* smooth
* understated
* elegant
* professional

Preferred animations:

* fade-in reveals
* soft upward motion
* staggered section reveals
* subtle hover states
* gentle image scaling

Avoid:

* excessive motion
* bouncing effects
* dramatic transforms
* flashy transitions
* over-animated UI

The animation should support the experience, not dominate it.

---

# Component Direction

## Cards

Cards should feel:

* clean
* minimal
* spacious
* lightly elevated

Avoid:

* thick borders
* excessive shadows
* cluttered interiors

---

## Buttons

Buttons should feel:

* modern
* restrained
* refined

Avoid:

* giant CTA buttons
* glowing buttons
* overly rounded playful styles

---

## Sections

Every section should feel intentionally composed.

Use:

* varying section structures
* visual rhythm
* alternating layouts
* balanced spacing

Avoid:

* repetitive layouts
* generic landing page structures
* excessive symmetry everywhere

---

# Leadership Section Direction

Leadership sections should feel:

* executive
* premium
* globally credible

Preferred structure:

* alternating image/text layouts
* editorial composition
* spacious biographies
* elegant profile presentation

Avoid:

* startup team cards
* playful staff sections
* oversized biographies

---

# Services Section Direction

Services should feel:

* structured
* professional
* easy to scan

Use:

* concise descriptions
* elegant visual hierarchy
* refined supporting imagery

Avoid:

* giant bullet dumps
* overly technical formatting
* dense corporate layouts

---

# Responsiveness

The site should feel excellent across:

* desktop
* tablet
* mobile

Desktop should feel especially:

* spacious
* editorial
* premium

Avoid collapsing everything into identical stacked layouts too early.

---

# Technical Expectations

* Use clean reusable components.
* Keep layouts maintainable.
* Preserve accessibility and readability.
* Use semantic HTML structure where possible.
* Maintain consistent spacing systems throughout the app.

---

# Final Experience Goal

The final experience should feel like:

“A globally credible executive consulting and advisory firm with a modern editorial presence, refined structure, and premium digital sophistication.”
